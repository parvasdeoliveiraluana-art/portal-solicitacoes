# Portal de Solicitações Corporativas

Sistema desenvolvido para centralizar e organizar solicitações de cadastros corporativos, proporcionando um processo mais padronizado, organizado e de fácil acompanhamento.

## 📋 Sobre o projeto

O Portal de Solicitações Corporativas reúne em um único ambiente solicitações relacionadas a três plataformas utilizadas pela empresa:

- ☕ Expresso
- 🚗 Uber Corporativo
- 🚙 WebFrota

Cada modalidade possui um formulário específico, desenvolvido de acordo com as informações necessárias para o respectivo processo de cadastro.

## ⚙️ Principais funcionalidades

- Portal centralizado para abertura de solicitações
- Formulários específicos para cada plataforma
- Preenchimento organizado por etapas
- Validação e organização das informações
- Geração automática de ID para cada solicitação
- Registro centralizado das solicitações
- Painel administrativo para acompanhamento
- Pesquisa e filtros por plataforma e status
- Visualização detalhada das solicitações
- Atualização do status do atendimento

## 🖥️ Tecnologias utilizadas

- Google Apps Script
- Google Sheets
- HTML
- CSS
- JavaScript
- Git e GitHub
